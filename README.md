# SimplyEmail editor: bugs and feature requests

This public repository tracks bugs and improvements for the **SimplyEmail email editor**. The application source code is maintained separately in a private repository.

- [Report an editor bug](https://github.com/emparer/simplyemail-editor-issues/issues/new?template=01-editor-bug.yml)
- [Suggest an editor improvement](https://github.com/emparer/simplyemail-editor-issues/issues/new?template=02-editor-feature.yml)
- [Browse existing reports](https://github.com/emparer/simplyemail-editor-issues/issues)
- [Open the editor](https://simplyemail.vercel.app/editor)
- [Read the help page](https://simplyemail.vercel.app/help)

## Before reporting

Search existing issues first. For a new bug, include the steps to reproduce it, the expected result, and your browser and operating system. Export problems are easier to investigate when you also describe how you opened or sent the file and which mail applications were involved.

Reports and attachments are public. Use example content; remove customer details, private email text, passwords and tokens before posting. A GitHub account is needed to submit or comment on issues.

## Scope

Editor canvas tools, selection, zoom, text formatting, blocks, columns, images, borders, imports, exports, and opening/saving editor projects belong here. Keep each issue focused on one problem or proposal. This repository contains reporting forms and documentation, not application source or a deployed website.

## Follow-up

The maintainer may ask for a smaller example or more details. Updates and resolutions will be recorded in the issue thread. There is no guaranteed response time.
